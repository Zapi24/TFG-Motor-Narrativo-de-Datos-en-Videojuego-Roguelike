# TFG-Motor-Narrativo-de-Datos-en-Videojuego-Roguelike

Repositorio de mi trabajo de Fin de grado en Ingeniería Informática.

El presente Trabajo de Fin de Grado, titulado **"Desarrollo de motor narrativo orientado a datos integrado en videojuego con mecánimcas Action Roguelike"**, se plantea como un proyecto interdisciplinar en colaboración con una estudiante del grado en Bellas Artes. El objetivo es desarrollar un videojuego 2D empleando el motor de código abierto "Godot Engine", en el que aplicaremos un flujo de trabajo propio en la industria donde se separa la arquitectura del software de la dirección del arte.

La justificación técnica de este título radica en la implementación de una arquitectura orientada a datos. Este motor narrativo leerá de forma dinámica datos estructurados desde hojas de cálculo para automatizar la creación de diálogos, fondos y sprites. Este diseño garantiza un sistema limpio de dependencias, permitiendo al perfil de Bellas Artes crear y modificar escenas de la novela visual con total autonomía sin modificar el propio código del juego.

Toda esta estructura funcionará en conjunto con el desarrollo propio del videojuego con mecáninas enfocadas en un "Action Roguelike", exigiendo la programación de sistemas optimizadas para la IA de enemigos y el procesamiento de físicas. El avance del proyecto estará fundamentado en prácticas de Ingeniería de software, estableciendo reuniones periódicas de coordinación para integrar los assets gráficos y evaluar el rendimiento general de la aplicación.
